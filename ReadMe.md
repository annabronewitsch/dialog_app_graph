- В какой среде разрабатывалась программа: Microsoft Visual Studio 2022

## 📝 Требования к расчету и программе:
1. построение графика гипоциклоиды;
2. стирание графика;
3. Обеспечить кроме ручного ввода t автоматический расчет этого параметра для k=m/n (m и n – целые), обеспечивающего рисование замкнутого графика;
4. выполнять расчеты и графическую визуализацию результатов в соответствии с введенными пользователем параметрами с поддержкой универсальной кодировки символов Unicode;
5. иметь графический пользовательский интерфейс; 
6. применять разработанную схему передачи и преобразования данных в проекте [**Data Flow Diagram**](https://github.com/annabronewitsch/dialog_app_graph/blob/e7f75d68cb4801c58684cbcb9fe59df04fe60774/data%20flow%20diagramm%20and%20variables.md) с программными интерфейсами передачи данных и диаграммой классов с указанием наследования и программных интерфейсов;     


   
## 📚 Алгоритм решения задачи 

### 1. Создание диалогового окна с элементом отображения графика

- В редакторе ресурсов Visual Studio создаётся окно типа Dialog;
- На форму добавляется элемент управления CStatic, предназначенный для рисования графика;
- Элементу присваивается уникальный идентификатор (IDC_ARTIST);
- В коде создаётся пользовательский класс (CArtist), наследуемый от CStatic, и подключается к элементу через SubclassDlgItem;

### 2. Расчёт точек кривой гипоциклоиды
- Вводятся параметры: большие и малые радиусы, множитель, радиус ролика и т.п.;
- Используется математическая формула гипоциклоиды для расчёта координат (x, y) каждой точки;
- Вычисления организуются в цикле с шагом по углу в радианах;

### 3. Задание шага независимой переменной: шаг (step) рассчитывается по формуле: step = 2π / (ширина окна − 2 × BORDER_W); 

### 4. Перевод координат в координаты окна: каждая точка преобразуется из математических координат в координаты клиентской области окна с использованием вспомогательного класса (m_Trans), учитывающего масштаб и центр окна;

### 5. Вращение фигуры (если используется анимация): выполняется поворот каждой точки на угол m_rotationAngle вокруг центра окна, применяется матрица поворота с учётом смещения относительно центра.

### 6. Выбор ручки (инструмента рисования)
- Создаётся объект CPen нужного цвета и толщины для отрисовки координатных осей и самой кривой;
- Ручка выбирается в текущий контекст рисования (SelectObject);

### 7. Отрисовка графика и координатных осей
- В OnPaint() перед рисованием выполняется заливка фона (FillSolidRect);
- Строится график с помощью MoveTo и LineTo по всем точкам вектора;
- Дополнительно строятся координатные оси;

### 8. Построение полного оборота кривой: чтобы получить замкнутый график, расчёт выполняется от угла 0 до 2π * f, где f — число оборотов (чем больше f, тем сложнее и плотнее становится траектория);

### 9. Обновление графика и анимация
- При изменении параметров (радиусы, f, r) вызывается функция Calc(), пересчитывающая точки;
- Для анимации используется SetTimer и метод OnTimer(), где угол поворота постепенно увеличивается;
- После каждого изменения вызывается RedrawWindow() с флагом RDW_ERASE для обновления окна;

### 10. Дополнительные функции:
- Возможность смены цвета фона через SetBkColor();
- Смена цвета графика с помощью выпадающего списка (ComboBox);
- Управление анимацией по нажатию кнопки (включение/отключение таймера);
