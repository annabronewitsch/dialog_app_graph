# 🔘 Оконное приложение для построения графика гипоциклоиды.
- Язык, на котором написана программа: C++
-В какой среде разрабатывалась программа: Microsoft Visual Studio 2022
- Программа написана под руководством доцента кафедры РЭС к.т.н. И.Ю. Ситникова в качестве курсовой работы по предмету «информационные технологии» (2 семестр).
- Репозиторий будет открыт на время отбора на стажировку YADRO Импульс 2026. 

## 📝 Требования к расчету и программе:
1. построение графика гипоциклоиды;
2. стирание графика;
3. Обеспечить кроме ручного ввода t автоматический расчет этого параметра для k=m/n (m и n – целые), обеспечивающего рисование замкнутого графика;
4. выполнять расчеты и графическую визуализацию результатов в соответствии с введенными пользователем параметрами с поддержкой универсальной кодировки символов Unicode;
5. иметь графический пользовательский интерфейс; 
6. применять разработанную схему передачи и преобразования данных в проекте Data Flow Diagram с программными интерфейсами передачи данных и диаграммой классов с указанием наследования и программных интерфейсов;

## 📚 Алгоритм решения задачи 

1. Создание диалогового окна с элементом отображения графика

1.1. В редакторе ресурсов Visual Studio создаётся окно типа Dialog;
1.2. На форму добавляется элемент управления CStatic, предназначенный для рисования графика;
1.3. Элементу присваивается уникальный идентификатор (IDC_ARTIST);
1.4. В коде создаётся пользовательский класс (CArtist), наследуемый от CStatic, и подключается к элементу через SubclassDlgItem;

2. Расчёт точек кривой гипоциклоиды
2.1. Вводятся параметры: большие и малые радиусы, множитель, радиус ролика и т.п.;
2.2. Используется математическая формула гипоциклоиды для расчёта координат (x, y) каждой точки;
2.3. Вычисления организуются в цикле с шагом по углу в радианах;

3. Задание шага независимой переменной: шаг (step) рассчитывается по формуле: step = 2π / (ширина окна − 2 × BORDER_W); 

4. Перевод координат в координаты окна: каждая точка преобразуется из математических координат в координаты клиентской области окна с использованием вспомогательного класса (m_Trans), учитывающего масштаб и центр окна;

5. Вращение фигуры (если используется анимация): выполняется поворот каждой точки на угол m_rotationAngle вокруг центра окна, применяется матрица поворота с учётом смещения относительно центра.

6. Выбор ручки (инструмента рисования)
6.1. Создаётся объект CPen нужного цвета и толщины для отрисовки координатных осей и самой кривой;
6.2. Ручка выбирается в текущий контекст рисования (SelectObject);

7. Отрисовка графика и координатных осей
7.1. В OnPaint() перед рисованием выполняется заливка фона (FillSolidRect);
7.2. Строится график с помощью MoveTo и LineTo по всем точкам вектора;
7.3. Дополнительно строятся координатные оси;

8. Построение полного оборота кривой: чтобы получить замкнутый график, расчёт выполняется от угла 0 до 2π * f, где f — число оборотов (чем больше f, тем сложнее и плотнее становится траектория);

9. Обновление графика и анимация
9.1. При изменении параметров (радиусы, f, r) вызывается функция Calc(), пересчитывающая точки;
9.2. Для анимации используется SetTimer и метод OnTimer(), где угол поворота постепенно увеличивается;
9.3. После каждого изменения вызывается RedrawWindow() с флагом RDW_ERASE для обновления окна;

10. Дополнительные функции:
10.1. Возможность смены цвета фона через SetBkColor();
10.2. Смена цвета графика с помощью выпадающего списка (ComboBox);
10.3. Управление анимацией по нажатию кнопки (включение/отключение таймера);

##  ✅ Выбор и обоснование типов переменных 
1. Список типов переменных: 
1.1. int — хранит целые числа без десятичных знаков (пример: int BOOL)
1.2. float — хранит дробные числа, содержащие один или несколько десятичных знаков.
1.3. CString string — строковый тип данных      .
1.4. bool — хранит значения с двумя состояниями: истина или ложь     (пример OnInitDialog).
1.5. double — тип данных для хранения чисел с плавающей точкой двойной точности. Примеры:
m_R (double) — переменная для ввода радиуса большей окружности;
m_r (double) — переменная для ввода радиуса меньшей окружности;
m_f (double) — переменная для ввода параметра f;

2. Классы из Windows/MFC
2.1. CPoint — точка с координатами (x, y);
2.2. CPen — настройка линий (цвет, толщина);
2.3. CString — класс для работы со строками;
2.4. CStatic — базовый класс статического элемента управления;
2.5. CRect — прямоугольник (границы: лево, верх, право, низ);
2.6. CBrush — настройка заливки (цвет, узор);
2.7. CDialogEx — окно программы (кнопки, поля ввода и т.д.);
2.8. CButton — кнопка;
2.9. CComboBox — выпадающий список;

3. Пользовательские классы
3.1. CArtist — рисует оси (X и Y) и график;
3.2. CTrans — линейное преобразование координат для вписывания графика в окно;
3.3. CMFCApplication2Dlg — главное окно программы (содержит кнопки, поля ввода и вывода);
3.4. CAboutDlg — окно «О программе»;

4. Дополнительные структуры
4.1. m_vecPt (std::vector<CPoint>) — массив точек графика;
  
5. CDC — класс контекста устройств
5.1. dc.FillSolidRect -заполнение прямоугольной области сплошным цветом; 
5.2. dc.SelectClipRgn -устанавливает регион обрезки для контекста устройства, все последующие операции рисования будут ограничены этим регионом;
5.3. dc.SelectObject -позволяет выбрать графический объект (например, кисть, шрифт, перо) для использования в контексте устройства;
5.4. dc.MoveTo -перемещает текущую позицию пера в заданные координаты;
5.5. dc.LineTo -рисует линию от текущей позиции пера до указанных координат;
5.6. dc.GetSafeHdc -возвращает дескриптор контекста устройства (HDC);
5.7. dc.DrawIcon- используется для отображения иконок приложений, системных значков и других графических элементов интерфейса.

Это приложение MFCApplication2 автоматически создано с помощью мастера приложений. Это приложение демонстрирует основные принципы использования классов Microsoft Foundation; оно также может использоваться в качестве основы для написания собственных приложений.

В этом файле представлена сводка содержимого всех файлов, входящих в состав приложения MFCApplication2.

MFCApplication2.vcxproj
    Это основной файл проекта VC++, создаваемый с помощью мастера приложений. Он содержит данные о версии языка Visual C++, использованной для создания файла, а также сведения о платформах, конфигурациях и функциях проекта, выбранных с помощью мастера приложений.

MFCApplication2.vcxproj.filters
    Это файл фильтров для проектов VC++, созданный с помощью мастера приложений. Он содержит сведения о сопоставлениях между файлами в вашем проекте и фильтрами. Эти сопоставления используются в среде IDE для группировки файлов с одинаковыми расширениями в одном узле (например CPP-файлы сопоставляются с фильтром "Исходные файлы").

MFCApplication2.h
    Это основной файл заголовка приложения.
    Он содержит прочие заголовки, относящиеся к проекту (включая Resource.h), а также объявляет класс приложения CMFCApplication2App.

MFCApplication2.cpp
    Это основной исходный файл приложения, в котором содержится класс приложения CMFCApplication2App.

MFCApplication2.rc
    Он представляет собой список всех ресурсов Microsoft Windows, используемых программой. В него включены значки, точечные рисунки и курсоры, хранящиеся в подкаталоге RES. Этот файл можно редактировать непосредственно в Microsoft Visual C++. Ресурсы проекта находятся в 1049.

res\MFCApplication2.ico
    Файл значка, используемый в качестве значка приложения. Этот значок включен с помощью основного файла ресурсов MFCApplication2.rc.

res\MFCApplication2.rc2
    Этот файл содержит ресурсы, которые нельзя редактировать в Microsoft Visual C++. В этот файл следует поместить все ресурсы, не редактируемые редактором ресурсов.
