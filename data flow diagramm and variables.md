### 1. Список типов переменных: 
- int — хранит целые числа без десятичных знаков (пример: int BOOL)
- float — хранит дробные числа, содержащие один или несколько десятичных знаков.
- CString string — строковый тип данных      .
- bool — хранит значения с двумя состояниями: истина или ложь     (пример OnInitDialog).
- double — тип данных для хранения чисел с плавающей точкой двойной точности. Примеры: m_R (double) — переменная для ввода радиуса большей окружности; m_r (double) — переменная для ввода радиуса меньшей окружности; m_f (double) — переменная для ввода параметра f;

### 2. Классы из Windows/MFC
- CPoint — точка с координатами (x, y);
- CPen — настройка линий (цвет, толщина);
- CString — класс для работы со строками;
- CStatic — базовый класс статического элемента управления;
- CRect — прямоугольник (границы: лево, верх, право, низ);
- CBrush — настройка заливки (цвет, узор);
- CDialogEx — окно программы (кнопки, поля ввода и т.д.);
- CButton — кнопка;
- CComboBox — выпадающий список;

### 3. Пользовательские классы
- CArtist — рисует оси (X и Y) и график;
- CTrans — линейное преобразование координат для вписывания графика в окно;
- CMFCApplication2Dlg — главное окно программы (содержит кнопки, поля ввода и вывода);
- CAboutDlg — окно «О программе»;

### 4. Дополнительные структуры
m_vecPt (std::vector<CPoint>) — массив точек графика;
  
### 5. CDC — класс контекста устройств
- dc.FillSolidRect -заполнение прямоугольной области сплошным цветом; 
- dc.SelectClipRgn -устанавливает регион обрезки для контекста устройства, все последующие операции рисования будут ограничены этим регионом;
- dc.SelectObject -позволяет выбрать графический объект (например, кисть, шрифт, перо) для использования в контексте устройства;
- dc.MoveTo -перемещает текущую позицию пера в заданные координаты;
- dc.LineTo -рисует линию от текущей позиции пера до указанных координат;
- dc.GetSafeHdc -возвращает дескриптор контекста устройства (HDC);
- dc.DrawIcon- используется для отображения иконок приложений, системных значков и других графических элементов интерфейса.
